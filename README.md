# Talaria (Alpha) — INTERNAL USE ONLY

Talaria combines T3 Code’s coding-agent workspace with Hermes bot integration for authorized Squarrel staff and internal testing. Independently maintained by Squarrel; these are not official T3 Tools or Hermes releases.

Hermes integration includes bot chats and side chats, profile creation/cloning, and panels for skills, identity, jobs and settings. Bot setup must be completed before first chat.

Hermes features require connected Talaria environment with separately installed and configured Hermes gateway. Installer includes integration UI, not Hermes runtime, preconfigured internal bots, provider credentials or chat history. Environment administrator configures Hermes; authorized staff connect through Settings → Connections using sign-in or pairing. Hermes owns bot configuration and history. Provider usage and tests can incur charges under connected account’s plan.

Current Hermes limits: bot Files/Terminal and bot rename/delete unavailable; memory and user entries view-only. Persistent model changes and adding provider keys supported only for default bot. Cloning copies supported settings, not credentials.

Windows x64 only. Experimental, unsigned builds provided “as is”, without warranty. Bugs and incomplete features expected. No public support commitment.

Download latest installer from Releases. Install first public-feed build once, then use in-app update button. No GitHub download token required for public feed. Updates use newest successfully published Talaria commit build.

Save work and back up important data before installing or updating. Updates restart app and interrupt running tasks. Windows can warn because installer is unsigned. Verify SHA-256 shown in release notes before running.

Downloads are public. Internal-use designation names intended audience; it does not limit who can download files or replace license terms. Internal connections require authorized sign-in or pairing. Downloading installer grants no access to Squarrel accounts or data.

Installer includes bundled app code and public connection settings. That code can be inspected. Personal chat history, account credentials and publishing tokens are not intended installer contents. Releases checked for known credential patterns; this check is not complete security audit.

Support: internal team channels only. Do not post secrets or private logs publicly.
